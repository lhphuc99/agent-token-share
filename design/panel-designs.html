Which to build

A (native tree) is already wired up — the Token Share container, the key icon, click-to-switch, inline share/remove. Pick it if you want to ship now; VS Code themes it for free.

B (cards) is the recommended upgrade once you want the countdown and the share flow to feel first-class — it maps cleanly onto a Webview reading the same store. C suits many accounts; D suits a switch-one-at-a-time habit.

All four drive the exact same commands underneath (switch · export · import · remove). The choice is only how the panel looks, so we can start on A and swap in a Webview later without touching the token logic.
